# Review Prompt: Read-Only Refactor Review

Task:

Perform a read-only review of the current repository state after the latest refactor step.

Review focus:

- structural clarity
- compatibility with the legacy workflow
- accidental business logic drift
- configuration safety
- beginner maintainability
- missing tests or missing migration notes

Constraints:

- do not edit files
- do not create files
- do not delete files
- use the current repository content as the only source of truth

Output style:

- concise
- structured
- findings first
- then open questions or risks
- then a short recommendation for the next step
